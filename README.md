
# 🍔 Swiggy Clone (Frontend)

A responsive **Swiggy Clone** built using **React.js**, featuring real-time data fetching from Swiggy APIs, dynamic routing, and state management using Redux.

---

## 🚀 Features

* 🔥 Live data using **Swiggy's public API**
* 🛒 Add to Cart functionality using **Redux**
* 🔄 Dynamic routing with **React Router**
* 📱 Fully responsive UI
* ⚡ Fast and smooth user experience

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **State Management:** Redux Toolkit
* **Routing:** React Router DOM
* **Styling:** CSS / Tailwind (update if you used one)
* **API:** Swiggy Live API

---

## 🔑 Key Functionalities

### 🧭 Routing

* Implemented using **React Router**
* Multiple pages like Home, Restaurant Menu, Cart

### 🛒 Cart Management

* Built using **Redux Toolkit**
* Add, remove, and update items dynamically

### 🌐 API Integration

* Fetches real-time restaurant and menu data
* Mimics real Swiggy experience

---

## ⚙️ Installation & Setup

1. Clone the repository

```
git clone https://github.com/Diksha-kumari-singh/swiggy-clone.git
```

2. Navigate to project folder

```
cd swiggy-clone
```

3. Install dependencies

```
npm install
```

4. Run the app

```
npm start
```
